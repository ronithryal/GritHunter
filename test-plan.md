## E2E / Manual Test Checklist

Run against real Perplexity Agent API + real GitHub API before launch.

### Pre-condition gate (required before any product work)
- [ ] Send "Find React Native engineers in SF who shipped App Store apps"
- [ ] Verify: ≥3 of 5 returned developers have at least one independently verifiable URL
- [ ] Verify: no hallucinated developers (all handles exist on github.com)

### Search mode
- [ ] NL query → cards appear progressively (5 cards within 30s)
- [ ] First card appears within 10s
- [ ] UI shows "5 of N found" counter
- [ ] Each evidence card: summary paragraph present, ≥1 signal tag, last_verified_at shown
- [ ] Signal tag URLs are clickable and resolve to real pages

### Similarity mode — repo URL
- [ ] github.com/facebook/react-native → results are RN engineers, not React core contributors
- [ ] github.com/vercel/next.js → results are Next.js ecosystem developers, not Vercel employees
- [ ] Very large repo (>10k stars) → results are domain engineers, not top maintainers

### Similarity mode — profile URL
- [ ] Paste a known GitHub profile → results are developers with comparable proof-of-work
- [ ] Results are not identical to the input profile's followers

### Error states
- [ ] Invalid GitHub URL (github.com/user/repo/issues) → inline error shown, no API call
- [ ] Rate limit hit (10 queries) → 429 message shown
- [ ] Perplexity API key revoked → "Search temporarily unavailable" shown
- [ ] Thin-signal developer → "Limited signal" label shown, card not removed or reordered

### Mode toggle
- [ ] Type GitHub URL while in Search mode → server switches to Similarity, UI hint shown
- [ ] Type plain text while in Similar to... mode → server switches to Search, UI hint shown
